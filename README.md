# Portfolio

Welcome to my personal portfolio built with [Next.js](https://nextjs.org), [React](https://react.dev), and TypeScript.

## Getting Started

To run the project locally:

```bash
npm install
npm run dev
```

Visit http://localhost:3000 in your browser.


# Features

- Modern React and Next.js stack
- TypeScript for type safety
- Responsive design
- Showcases my projects, skills, and contact information


# Editing

Start by modifying app/page.tsx to update the homepage. Changes are reflected automatically.


# Deployment

Deploy easily on Vercel or your preferred platform.
